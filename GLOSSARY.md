# Glossary

| Term | Meaning |
|---|---|
| Automation | A company workflow/process automated by a tool or script, tracked as one entry in this dashboard's registry. |
| ROI card | The per-automation view showing time/money saved and status, as described in `ROI.md`. |
| Skill (registry field) | A reusable capability an *automation* uses to do its work — automations in the registry list which skills they use. Distinct from "the self-service skill" in `ROADMAP.md`/`ARCHITECTURE.md`'s Data Flow, which is a future registration tool for *this project itself*, not a registry entry. |
| Registry | The full list of tracked automations and their metadata (category, owner, links, ROI) — this dashboard's core data. |
