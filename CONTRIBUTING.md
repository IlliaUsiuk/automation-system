# Contributing

## Filing a good issue
Use the bug report / feature request templates under `.github/ISSUE_TEMPLATE/`.

## Submitting a good PR
Branch off `main` (GitHub flow), open a PR back into `main`, and fill in the
`.github/PULL_REQUEST_TEMPLATE.md` checklist. Use [Conventional Commits](https://www.conventionalcommits.org/)
for commit messages. Currently reviewed solo by the project owner.

## Local dev setup
Node.js (LTS) + npm, Postgres running locally or reachable via `DATABASE_URL`. See
`docs/getting-started.md`.

## Code of conduct
See `CODE_OF_CONDUCT.md`.
