# Roadmap

## Now
- Registry of automations: which skills/tools each one uses, category (what it
  automates), description, related/dependent automations, owner, links out to the
  automation's GitHub repo and ClickUp task.
- ROI card per automation: time/money saved, status.
- Login/access control for external (beyond-Supplax-network) access.

## Next
- Telegram alerts when an automation breaks/fails.
- A skill that lets a worker self-register their automation's access into this
  project via GitHub, instead of it being added by hand.

## Later
- Daily token-consumption tracking per automation.
- ROI presented as a richer visual artifact (presentation/diagram-style view), design
  TBD — see `ROI.md` and the note in `PIPELINE.md` §1 about the design pass planned
  after this bootstrap.
