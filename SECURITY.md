# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| main (pre-release) | yes |

## Reporting a Vulnerability
This is an internal Supplax project with planned external (beyond-corporate-network)
login access, which is why this file exists at all — see `PIPELINE.md` §5. Report a
vulnerability directly to the project owner rather than opening a public issue; the
actual contact channel is a placeholder pending the design stage (Telegram support
channel — see `SUPPORT.md`).
